## Brand & Style

This design system blends futuristic cyberpunk energy with sophisticated glassmorphism, engineered specifically for a mainstream consumer social network. The platform creates an atmosphere of immersive night-mode escapism while remaining tactile, approachable, and highly readable.

### Design Movement: Cyber-Glassmorphic
- **Core Aesthetic:** Volumetric layered glass, atmospheric violet-black voids, radiant neon chromatic gradients, and razor-sharp typographic geometry.
- **Tone:** Electric, social, visionary, sleek, and intuitive.
- **Target Audience:** Next-generation digital natives, creators, curators, and social users seeking an elevated sensory interface without visual clutter or alienating industrial roughness.
- **Emotional Response:** Inspires forward-looking curiosity, social prestige, and intuitive flow within an illuminating nocturnal cosmos.

## Colors

The palette establishes an ultra-deep cosmic base punctuated by high-vibrancy violet, neon magenta, and electric cyan signals.

### Color Tiers
- **Void Bases (Neutrals):**
  - Cosmic Void (Canvas): `#0B0813`
  - Abyssal Purple (Surface Layer 1): `#120A21`
  - Nightglass (Surface Layer 2): `#1A1033`
  - Translucent Glass Fill: `rgba(26, 16, 51, 0.65)`
- **Primary (Electric Violet / Ultraviolet):**
  - Ultraviolet Core: `#8B5CF6`
  - Deep Spectral Violet: `#6D28D9`
  - Violet Glow Highlight: `#A78BFA`
- **Secondary (Neon Magenta / Hot Pink):**
  - Neon Magenta: `#D946EF`
  - Cyber Pink Glow: `#EC4899`
- **Tertiary (Electric Cyan):**
  - Hyper Cyan: `#06B6D4`
  - Cyan Flare: `#22D3EE`
- **Text & Foreground:**
  - High-Emphasis Content: `#F8FAFC`
  - Medium-Emphasis / Subtext: `#94A3B8`
  - Subtle Labels / Meta: `#64748B`
  - Glass Dividers & Ghost Strokes: `rgba(255, 255, 255, 0.12)`

### Neon Gradients
- **Hyperline Gradient:** Linear `135deg` from `#8B5CF6` (violet) to `#EC4899` (magenta) to `#06B6D4` (cyan). Used for glowing active rings, prominent CTAs, and active navigation indicators.
- **Border Sheen:** Linear `180deg` from `rgba(217, 70, 239, 0.4)` to `rgba(109, 40, 217, 0.15)`.

## Typography

The type scale balances futuristic architectural presence with exceptional social readability.

- **Headlines & Labels (`Space Grotesk`):** Provides sharp, mechanical cadence, giving feeds, titles, interactive controls, and numerical badges a distinctive techno-futurist voice.
- **Body Text (`Plus Jakarta Sans`):** Warm, geometric, and exceptionally legible in dark-mode environments. Avoids eye strain across long social posts, comment sections, and messaging threads.
- **Hierarchy Rules:** 
  - Keep display titles strictly in `#F8FAFC` or masked with the violet-to-cyan gradient on highlighted hero titles.
  - Body copy uses `#94A3B8` for secondary text to maintain clear contrast ratios against tinted glass backgrounds.

## Layout & Spacing

The layout is built on a responsive 12-column fluid grid system that condenses to 8 columns on tablet and 4 columns on mobile.

### Spatial Rhythm
- **Micro-gaps (`space-xs`, `space-sm`):** Reserved for icon-to-text spacing, status tags, and avatar-to-handle pairings.
- **Card Padding & Component Rhythm (`space-md`, `space-lg`):** Standard interior padding for glass panels, interactive cards, and modular social feeds.
- **Section Spacing (`space-xl`):** Dedicated distance between primary feed blocks, story bars, and sticky floating docks.

### Breakpoints & Reflow
- **Mobile (< 768px):** 4 columns, `margin-mobile` (16px), bottom sticky frosted navigation dock, full-width story reels.
- **Tablet (768px – 1024px):** 8 columns, compact persistent sidebar, multi-column modular card grids.
- **Desktop (> 1024px):** 12 columns, max content constraint of 1280px centered within `#0B0813`, tri-pane layout (Navigation Drawer, Main Feed, Dynamic Discovery/Direct Messaging).

## Elevation & Depth

Visual hierarchy uses physical glass light-refraction combined with spectral light-bleed rather than conventional drop shadows.

### Glassmorphic Surface Tiers
- **Tier 0 (Backdrop):** Raw cosmic void `#0B0813` with static atmospheric radial gradients (`rgba(109, 40, 217, 0.15)` and `rgba(217, 70, 239, 0.08)`).
- **Tier 1 (Base Cards & Feed Items):**
  - Background: `rgba(18, 10, 33, 0.6)`
  - Backdrop Filter: `blur(16px) saturate(180%)`
  - Border: 1px solid `rgba(255, 255, 255, 0.08)`
  - Shadow: `0 8px 32px 0 rgba(0, 0, 0, 0.45)`
- **Tier 2 (Floating Modals, Flyouts & Menus):**
  - Background: `rgba(26, 16, 51, 0.75)`
  - Backdrop Filter: `blur(24px) saturate(200%)`
  - Border: 1px solid `rgba(217, 70, 239, 0.3)`
  - Shadow: `0 16px 48px 0 rgba(0, 0, 0, 0.6), 0 0 24px 0 rgba(109, 40, 217, 0.25)`
- **Tier 3 (Active Overlays & Floating Badges):**
  - Background: `rgba(35, 20, 68, 0.85)`
  - Backdrop Filter: `blur(32px)`
  - Glow: `0 0 16px rgba(139, 92, 246, 0.4)`

### Neon Edge Highlighting
Active or featured components utilize pseudo-element border masks with linear gradients (Violet `#8B5CF6` to Magenta `#EC4899`), producing an internally illuminated filament edge.

## Shapes

The interface balances cybernetic structure with approachable consumer ergonomics. 

- **Level 2 Foundation:** Base elements (input fields, buttons, small cards) utilize `0.5rem` (8px). Medium feed cards and modals utilize `rounded-lg` (`1rem` / 16px). Major platform drawers and hero panels utilize `rounded-xl` (`1.5rem` / 24px).
- **Pill Exceptions:** Avatars, floating micro-badges, pill buttons, story rings, and filter chips are fully pill-shaped (`9999px`) to contrast with the angular geometric type and structured glass cards.

## Components

### Buttons
- **Primary Cyber Glow:** Background gradient (`135deg`, `#8B5CF6` to `#D946EF`), text `#FFFFFF`, rounded `9999px` or `0.5rem`. Box-shadow: `0 0 20px rgba(139, 92, 246, 0.45)`. On hover, scale 1.02 with intensified luminescence (`0 0 28px rgba(217, 70, 239, 0.6)`).
- **Secondary Glass:** Background `rgba(255, 255, 255, 0.05)`, border `1px solid rgba(255, 255, 255, 0.15)`, text `#F8FAFC`, backdrop blur `12px`. On hover: `border-color: #8B5CF6`, background `rgba(139, 92, 246, 0.15)`.
- **Tertiary Ghost:** Transparent background, text `#A78BFA`. On hover: text `#F8FAFC`, background `rgba(255, 255, 255, 0.05)`.

### Cards (Social Posts & Feeds)
- Built with Tier 1 Glass. 
- Integrated header featuring user avatar with a 2px glowing gradient status ring, username in `Space Grotesk`, and handle in `#64748B`.
- Content space framed with subtle horizontal dividers (`rgba(255, 255, 255, 0.06)`).
- Action bar (likes, shares, comments) with micro-interactions that trigger localized cyan/magenta particle or bloom effects.

### Floating Micro-Badges
- Ultra-compact tags (`label-badge`, uppercase, `letter-spacing: 0.08em`).
- Frosted background (`rgba(11, 8, 19, 0.8)`), border `1px solid currentColor`.
- Color states: Live (Neon Magenta `#D946EF`), Verified / Creator (Electric Cyan `#06B6D4`), Trending (Ultraviolet `#8B5CF6`).

### Chips & Filter Tags
- Pill-shaped (`rounded-full`), padding `0.375rem 0.875rem`.
- Inactive: `rgba(255, 255, 255, 0.05)` fill, `rgba(255, 255, 255, 0.1)` border, `#94A3B8` text.
- Active: Violet-to-magenta linear gradient fill, white text, neon shadow bloom.

### Form Inputs
- Background: `rgba(18, 10, 33, 0.8)`.
- Border: `1px solid rgba(255, 255, 255, 0.1)`.
- Focus State: Border color `#8B5CF6`, outline none, box-shadow `0 0 0 3px rgba(139, 92, 246, 0.25)`.
- Text color `#F8FAFC` with placeholder `#64748B`.

### Checkboxes & Radio Controls
- Custom controls with dark violet glass fills.
- Checked state fills with `#8B5CF6` and emits a subtle neon cyan check indicator with a faint ambient glow.

### Floating Nav Dock (Mobile / Desktop Quick Actions)
- Centered floating glass capsule with backdrop blur `24px`, border `1px solid rgba(255, 255, 255, 0.15)`.
- Active icons switch from `#64748B` to `#F8FAFC` anchored by an electric cyan glowing dot beneath the icon.

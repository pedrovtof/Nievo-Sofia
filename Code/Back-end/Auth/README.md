# Auth Microservice

## 1. Overview
The **Auth** microservice is built using **FastAPI** to provide authentication, user identity management, credential validation, and security token handling across the Sofia platform.

## 3. Configuration & Environment

Create a `.env` file based on [`.env-example`](file:///home/pedrovotf/Desktop/Projects/Nievo-Sofia/Code/Back-end/Auth/.env-example):

```bash
cp .env-example .env
```

| Variable | Description | Default |
| :--- | :--- | :--- |
| `APP_NAME` | Name of the service | `FastAPI Application` |
| `APP_VERSION` | Semantic version string | `1.0.0` |
| `DEBUG` | Enable debug mode | `False` |
| `ENVIRONMENT` | Environment name (development/production) | `development` |
| `PORT` | Local service port | `8000` |
| `TELEMETRY_TRACING` | OpenTelemetry tracing enablement | `False` |
| `DATABASE_URL` | SQLAlchemy connection string | `sqlite:///./auth.db` |

## 4. Setup & Running Locally

### 4.1 Install Dependencies
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 4.2 Run Migrations
```bash
alembic upgrade head
```

### 4.3 Run the Application
```bash
uvicorn src.main:app --reload --port 8000
```

---

## 5. Endpoints & Documentation

Interactive API documentation is automatically generated by FastAPI:
- **Swagger UI**: `http://localhost:8000/docs`
- **ReDoc UI**: `http://localhost:8000/redoc`
- **Health Check**: `GET http://localhost:8000/health`
- **User Registration**: `POST http://localhost:8000/v1/auth/`
- **Exception Diagnostic**: `GET http://localhost:8000/exception`

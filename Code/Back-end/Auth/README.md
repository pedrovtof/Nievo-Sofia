# Auth Microservice

## 1. Overview
The **Auth** microservice is built using **FastAPI** and **SQLAlchemy 2.0** to provide authentication, user identity management, credential validation, and security token handling across the Sofia platform.

## 3. Configuration & Environment

Create a `.env` file based on [`env-example.md`](./env-example.md):

| Variable | Description | Default |
| :--- | :--- | :--- |
| `APP_NAME` | Name of the service | `Sofia-Auth` |
| `APP_VERSION` | Semantic version string | `0.1.0` |
| `DEBUG` | Enable debug mode | `False` |
| `ENVIRONMENT` | Environment name (development/production) | `development` |
| `PORT` | Local service port | `8000` |
| `TELEMETRY_TRACING` | OpenTelemetry tracing enablement | `True` |
| `PGSQL_DATABASE_AUTH_MIGRATION_CONNECTION_STRING` | PostgreSQL Alembic migration connection string (`app_migration_accounts`) | `postgresql://...` |
| `PGSQL_DATABASE_PLATFORM_AUTH_ACCOUNTS_CONNECTION_STRING` | PostgreSQL application runtime connection string (`platform_auth`) | `postgresql://...` |
| `SALT_ENCRYPT_PASSWORD` | Cryptographic salt reference for password encryption configuration | `<generated-salt>` |
| `ENCODE_ENCRYPT_PASSWORD` | Character encoding used for bcrypt password hashing | `utf-8` |
| `REGEX_FOR_PASSWORD` | Password complexity validation regular expression | `^(?=.*[0-9])(?=.*[a-z])(?=.*[A-Z])(?=.*\W)(?!.* ).{8,16}$` |
| `MIN_AGE_FOR_ACCOUNT` | Minimum age required to register an account | `8` |
| `MAX_AGE_FOR_ACCOUNT` | Maximum age allowed to register an account | `90` |

## 4. Setup & Running Locally

### 4.1 Install Dependencies
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 4.2 Run Migrations
```bash
alembic upgrade head
```

### 4.3 Run the Application
```bash
uvicorn src.main:app --reload --port 8000
```

## 5. Endpoints & Documentation

Interactive API documentation is automatically generated by FastAPI:
- **Swagger UI**: `http://localhost:8000/docs`
- **ReDoc UI**: `http://localhost:8000/redoc`
- **Health Check**: `GET http://localhost:8000/health`
- **User Registration**: `POST http://localhost:8000/api/v1/signup/user`
- **Exception Diagnostic**: `GET http://localhost:8000/exception`

For architecture and sequence diagrams, refer to the project [Documentation](../../../Documentation/config/docs/).
